SIGMA FUTURISTE - Projet Android Expo

Ce dossier contient le code App.js et les fichiers de configuration nécessaires pour préparer une compilation Android avec Expo EAS Build.

Dépendances prévues : Expo SDK 54, React Native, Image Picker, Secure Store, AsyncStorage, SVG et Expo Vector Icons.

Important : le projet doit être vérifié et compilé avant utilisation. Les fonctions qui appellent Claude nécessitent une clé API valide configurée dans l'application. Les graphiques Twelve Data nécessitent également une clé API Twelve Data ; les données Binance sont utilisées pour BTC/ETH.
